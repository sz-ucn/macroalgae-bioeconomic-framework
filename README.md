# Supplementary Material S1

## Reproducible daily-step bioeconomic framework for commercial macroalgae cultivation

This supplement accompanies the manuscript *A methodological framework for
continuous-time economic valuation of commercial macroalgae cultivation*. It
is an illustrative, daily-step implementation of a continuous-time
bioeconomic framework. It is not calibrated for a particular species, site,
technology, currency, or commercial project.

## Contents

- `bioeconomic_framework.py`: model, threshold calculations, figures, and CSV output.
- `test_bioeconomic_framework.py`: automated regression tests.
- `requirements.txt`: Python dependencies.
- `outputs/`: reference outputs included with this package. Running the model regenerates and overwrites them.

## Requirements and execution

Python 3.10 or later is recommended.

```bash
python -m venv .venv
source .venv/bin/activate       # Linux/macOS
# .venv\Scripts\activate        # Windows
pip install -r requirements.txt
python -m unittest -v
python bioeconomic_framework.py
```

## Corrected terminal-event policy

The implementation deliberately applies two terminal rules:

1. A cohort is sown only when its full cultivation cycle ends on or before the
   stated project horizon. A crop that is still in cultivation at the terminal
   date is not planted unless the model is explicitly extended to assign it a
   terminal value.
2. Reinvestment is booked only at dates strictly before the project horizon.
   No replacement investment is charged on the last simulation day.

These rules ensure that the illustrative horizon does not contain costs with
no modeled benefit. `cohort_schedule.csv` records every allowed sowing and
harvest date, making the policy auditable.

## Tax and depreciation treatment

The model uses straight-line tax depreciation for the initial investment and
each scheduled replacement investment. At every time step:

```text
taxable income = revenue - operating cost - depreciation
tax = max(taxable income, 0) × tax rate
free cash flow = revenue - operating cost - tax
                 - investment - reinvestment + residual value
```

Depreciation therefore affects cash flow only through taxes; it is not
subtracted a second time as a cash expense. The illustrative model assumes no
tax-loss carry-forward, tax credit, debt financing, working-capital movement,
or tax on asset disposal. These features should be added when warranted by a
specific appraisal.

## Interpreting the price-yield frontier

`biomass_yield_multiplier` multiplies harvestable biomass directly. It is a
yield scenario, not a change in the carrying capacity or Gompertz growth-rate
parameter. With the default zero tax rate, the code uses the exact closed-form
zero-NPV sale-price multiplier for each yield multiplier. With a positive tax
rate, it retains the daily tax calculation and solves the break-even price
numerically. Results are written to `price_productivity_frontier.csv`.

The frontier identifies the combinations of price and harvestable biomass
yield that yield final NPV equal to zero under the other stated assumptions.
Combinations above the frontier are feasible and combinations below it are not.
The associated figure is generated by the code as
`figure_4_sensitivity_thresholds.png`.

## Outputs

Running `python bioeconomic_framework.py` writes the following files under
`outputs/`:

- `parameters.json`: baseline parameters used for the run.
- `run_summary.json`: final NPV, maximum simultaneous cohorts, and terminal-event check.
- `cohort_schedule.csv`: all scheduled sowing and harvest events.
- `baseline_timeseries.csv`: daily biological, operational, financial, tax, and discounted-cash-flow values.
- `price_productivity_frontier.csv`: exact break-even price for each yield multiplier.
- `price_productivity_grid.csv`: a compact NPV grid for sensitivity reporting.
- `cumulative_npv.png`: baseline cumulative NPV.
- `figure_4_sensitivity_thresholds.png`: reproducible two-panel scenario and threshold figure.

## Automated tests

The test suite verifies that:

- no cohort is sown without a harvest inside the horizon;
- no reinvestment is booked on the terminal date;
- depreciation reduces taxable income without being double-counted in free cash flow;
- the reported break-even frontier returns NPV equal to zero; and
- dated events must align with the selected time step.

## Scope and reproducibility

The daily grid is a numerical approximation to continuous-time growth and
discounting. All cash flows and event dates must use compatible temporal units.
The baseline values are illustrative; users should replace them with documented
biological, technological, market, fiscal, and financial assumptions. Before
publication, archive the final immutable version in a repository that assigns
a persistent identifier, and report its version, DOI, and licence in the
manuscript.
